# Activity 1.1

**Course:** CECS6001 - Object-Oriented Programming, Data Structures, and Algorithms

## Problems

The following are the exercises 

### 1. Sentence Reversal
Write a program that reads a sentence from the keyboard and writes it in reverse order to a file named `rev.txt`.

**Example:** `hello` → `olleh`

### 2. Intersecting Lines
Write a program including 2 classes: point and lines. Read four points from file “points.txt” and write to the screen if two lines are across each other.

### 3. Complex Number Addition
Write a program which reads a list of complex numbers from the text file “complex.txt” and writes out to the screen the sum of the list.

### 4. Greatest Common Divisor
Write a program to find the greatest common divisor of two integer numbers.

### 5. Number Operations
Write a program to read a list of real numbers from the text file “numbers.txt” and output to the file “numbers.txt” the list of numbers which has increasingly sorted.

Given 5 real numbers, write a program to calculate the sum of the greatest and smallest numbers.

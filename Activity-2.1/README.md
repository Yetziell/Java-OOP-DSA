# Activity 2.1

**Course:** CECS6001 - Object-Oriented Programming, Data Structures, and Algorithms

## Problems

The following are the exercises:

### 1. Class C

Recreate the class `C` example from page 10 of Drozdek's textbook. Place the class definition and the client program containing `main()` in two separate Java files.

### 2. Static Methods

Implement the example from page 12 of Drozdek's textbook and explain how the `static` method works. Place the `main()` method in a separate Java file, add your own functionality, and include a screenshot of the program's output.

### 3. Generic Classes

Explore Section 1.2 on generic classes. Modify the provided example so that the two array values are passed from the client program to the constructor instead of being assigned inside the constructor. Explain the data types chosen for the constructor parameters.
